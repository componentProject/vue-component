## API

### Props

| 参数 | 说明 | 类型 | 默认值 |
|------|------|------|--------|
| `options` | G2 图表配置选项 | `Record<string, any>` | `{}` |
| `render` | 渲染函数，接收 chart 实例 | ^[Function]`(chart: Chart) => any` | - |

### Events

该组件未定义事件。

### Slots

该组件无自定义插槽。

### Expose

| 方法名 | 说明 | 类型 |
|--------|------|------|
| `getChart` | 获取图表实例 | ^[Function]`() => Chart` |
